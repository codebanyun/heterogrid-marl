# 任务迁移集合

`.suite`是JSON格式的完整任务集合，不是单场景`EnvConfig`。使用独立扩展名以保持旧`configs/**/*.json`扫描和加载契约。

包含固定地图规模、近似固定密度规模、地图尺寸和角色组成四组。文件中的source/validation/test任务名互不重叠；规模组的验证配置与源配置相同，使用独立评估种子，不能把它记为OOD验证。

配置完整展开自原有6v6参考场景，不修改旧配置。蓝方策略保持rule，任务采样默认不读取test组。用法、观测mask和训练/评估命令见[任务迁移说明](../../docs/transfer.md)。

`fct_main.suite` 是联合迁移实验的冻结任务集合，含 S1–S6、V1–V6 和 T1–T8；`fct_extra_map_blue.suite` 提供额外地图及蓝方配比测试。文件名用于标识实验配置，不表示本仓库包含 FCT 算法实现。使用不同环境版本时，完整配置序列化可能增加默认字段，应记录版本并遵守检查点协议，避免无记录混用旧实验。
