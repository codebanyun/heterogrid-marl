# 通信、规模与角色配比实验

`replication.py` 为 SMPE 和 EPyMARL 原生 MAPPO 启动同一套实验，共享资源调度，分别记录算法结果。

## 配置与预算

- R5、P50、C1S 分别搭配 B0、M2、N2、D2，另有 C1S 的三个非均衡角色配比，共 15 个配置；保留提供的 JSON 角色顺序和平台，不重复均衡配置。
- R5 为红方距离半径 5；P50 为红方全连接、节点独立失联 50%；蓝方固定距离半径 10、无失联。C1S 双方显式无通信，覆盖顶层旧通信字段，不限制正常集中式训练。
- B0、M2、N2 和配比组不归一化奖励；D2 参考人数 6、生命值 480，仅伤害和击杀奖励缩放为 2/3。无火力不提前结束，平局奖励为 0，保持旧环境语义。
- 每个配置以 seed 42、43、44 从头训练，单算法 45 次、225M 团队环境步。算法超参数在所有配置间固定，仅自动适配输入输出维度。
- 每次目标 5,000,000 团队环境步，完成首次到达预算的完整新鲜对局批次后结束；实际额外步数严格小于 `batch_size_run * 200`。评估不计入训练预算。
- 训练环境种子按 `1000000 + training_seed * 100000000 + episode_index` 分配，索引从 0 开始；完成顺序不改变已分配种子。
- 初始及约每 250k 步做 64 局贪心验证，种子 1910042–1910105；不额外运行训练前独立测试。
- 结束模型和验证最优模型各做贪心 128 局、采样 128 局独立测试，种子 2800042–2800169，不参与选模和提前停止。

## 启动

```bash
python -m algorithms.common.replication \
  --output output/studies/20261113_comm_scale_roster_5m \
  --smpe-root /path/to/smpe_raw \
  --epymarl-root /path/to/epymarl
```

启动器冻结接入层、环境和两套外部源码，通过 `nohup` 启动联合调度器。目录必须不存在，不覆盖旧实验；`--prepare-only` 仅准备配置和源码。

协调目录的 `resource_control.json` 可运行中调整，限制总任务数、CPU/GPU 任务数、主存增长预留、显存余量及磁盘安全阈值。执行设备不改变网络或优化超参数。资源不足时等待空位，不缩小批次。停止时，核实 `status.json` 中调度器 PID 对应的命令和目录，再发送 `SIGTERM`；这会停止本轮所有任务。训练入口目前不提供完整进度恢复，中断结果不可当作完成结果。

## 结果

结果分别位于 `output/smpe/<实验名>/` 和 `output/epymarl_mappo/<实验名>/`，采用 `R5/B0/seed_42/` 等分层结构。每次完成后审计步数、种子、参数更新和真实动作回放，仅保留 `latest.pt`、`best.pt`，每个模型一局完整独立贪心回放及真实动作。所有独立测试逐局统计均保留，训练逐局日志无损 gzip 压缩。

`metrics.json` 保留验证曲线；`protocol_metrics.json` 包含测试胜率、超时率、接敌率、首次接敌时间、击杀比例、有效报告数、胜率 AUC、首次达到 80% 的步数、耗时和吞吐。AUC 按计划验证步数梯形积分，并另报除以训练预算的归一化值；80% 阈值同时记录计划与实际步数，未达到时为 `false` / `null`。总墙钟时间包括首尾评估；训练计时包括周期验证、不包括首尾评估。

`RESULTS.md` 与 `summary.json` 随完成任务更新，三个 seed 齐全才汇总均值和 SEM。主要报告结束模型独立测试胜率，最佳模型仅作补充；不同人数或角色配比不按绝对累计回报排名，N2 与 D2 差异不能全部归因于密度。
